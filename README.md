# Lun_term

Браузерный торговый терминал: свечи фьючерсов MOEX (**Si** — USD/RUB, **CNY** — CNY/RUB),
базовые индикаторы и **лунная лента знаков зодиака** с разметкой торговых зон
лунного цикла — инструмент для исследования связки «фаза Луны по знакам → поведение цены».

Прототип. Дальше подключаем остальные планеты и совмещаем циклы.

**Публикация на поддомене (без Node, обычный PHP-хостинг — СпринтХост/Таймвеб):**
см. [DEPLOY.md](DEPLOY.md) — залил файлы из `public/` и открыл по ссылке.

## Что уже есть

- **График свечей** на [KLineChart](https://klinecharts.com) (v10), таймфреймы **M5 / M15 / H1 / D1**.
- **Инструменты Si / CNY** с **авто-подбором ближнего контракта** (сервер сам находит
  ближайшую неистёкшую экспирацию по коду актива; запасной тикер — в конфиге).
- **Индикаторы:** SMA (20/50), EMA (9/21), сессионный **VWAP с полосами ±1σ / ±2σ**.
- **Объём** отдельной панелью.
- **Лунная лента ☾** (собственная отрисовка):
  - цвет каждой свечи — по знаку, в котором Луна (сейчас раскрашено **по стихиям**);
  - каждый знак разбит на **деканы по 10°** тонкими разделителями;
  - глиф знака и **текущий градус цифрой** в каждом декане (видно ход `9°→19°→29°`).
- **Циклы 1–6** — до шести независимых полос торговых зон (ЛОНГ / ШОРТ / рэндж).
  Цикл 1 — исследуемая лунная гипотеза; циклы 2–6 — заготовки под другие тела/циклы
  (тумблеры `1…6` в тулбаре включают/выключают полосы).
- **Инструменты рисования:** уровень, трендовая, прямоугольник, овал, стрелка/текст.
- Положение тел считается локально ([astronomy-engine](https://github.com/cosinekitty/astronomy),
  точность ±1′), интернет для астрологии не нужен. Поддержаны Луна, Солнце и планеты.

## Запуск (живые данные MOEX)

```bash
node server.js                 # → http://localhost:8080  (или PORT=9000 node server.js)
```

Зависимостей нет — только Node.js. Библиотеки уложены локально в `public/vendor/`.
Открой `http://localhost:8080` — на **локальной машине с доступом к MOEX** сразу
подтянутся живые свечи, а сервер сам определит ближний контракт (`SiU6`, `CRU6` и т.п.).

Как понять, что данные живые: в правом нижнем углу строка **«Данные: MOEX ISS»**.
Если там **«ДЕМО (нет связи с MOEX)»** — биржа недоступна (нет сети, запуск в облаке
или закрытый egress); интерфейс и лунная лента всё равно работают на демо-свечах.

Проверить, что именно отдаёт биржа, можно руками:

```bash
curl "http://localhost:8080/api/front?asset=Si"                       # ближний контракт
curl "http://localhost:8080/api/candles?secid=SiU6&iss=60&from=2026-07-20&till=2026-07-31"
```

Сервер сам обходит CORS, собирает **M5/M15** из 1-минуток и постранично тянет длинные
диапазоны. Логика ISS покрыта офлайн-тестом:

```bash
npm test
```

## Что и где настраивать

Почти всё вынесено в **`public/js/config.js`**:

| Что | Где |
|---|---|
| Актив/запасной тикер инструментов | `LUN.INSTRUMENTS` |
| Цвета 12 знаков | `LUN.SIGNS[].color` |
| **Циклы 1–6** (тело, вкл/выкл, зоны: границы °, bias, цвет) | `LUN.CYCLES` |
| Размер декана в ленте (по умолчанию 10°) | `LUN.SIGN_SUBDIVISION` |
| Периоды SMA/EMA, настройки VWAP | `LUN.INDICATORS` |

Ориентиры по градусам: `0°` = 0° Овна; 15° Близнецов = **75°**, 15° Весов = **195°**,
15° Козерога = **285°**.

## Структура

```
server.js              Node-сервер: статика + прокси MOEX ISS (пагинация, M5/M15, ближний контракт)
test/iss.test.js       офлайн-тест логики ISS-прокси (npm test)
public/
  index.html           разметка и подключение скриптов
  css/style.css        тёмная тема
  js/
    config.js          ← ПУЛЬТ: инструменты, знаки, циклы 1–6, индикаторы
    astro.js           положение тел (долгота → знак/градус), зоны цикла
    indicators.js      кастомные индикаторы: MoonSign, CycleStrip, VWAP±σ
    data.js            загрузчик свечей (ISS + демо-фолбэк)
    app.js             сборка терминала и UI
  vendor/              klinecharts, astronomy-engine (локально)
```
