# Lun_term

Браузерный торговый терминал: свечи фьючерсов MOEX (**Si** — USD/RUB, **CNY** — CNY/RUB),
базовые индикаторы и **лунная лента знаков зодиака** с разметкой торговых зон
лунного цикла — инструмент для исследования связки «фаза Луны по знакам → поведение цены».

Прототип. Дальше подключаем остальные планеты и совмещаем циклы.

## Что уже есть

- **График свечей** на [KLineChart](https://klinecharts.com) (v10), таймфреймы **M5 / M15 / H1 / D1**.
- **Индикаторы:** SMA (20/50), EMA (9/21), сессионный **VWAP с полосами ±1σ / ±2σ**.
- **Объём** отдельной панелью.
- **Лунная лента ☾** (собственная отрисовка):
  - цвет каждой свечи — по знаку, в котором Луна (сейчас раскрашено **по стихиям**);
  - глиф знака и **пройденный градус** (`♌ 27°`) у конца каждого знака.
- **Полоса «Цикл»** — торговые зоны лунного цикла (ЛОНГ / ШОРТ / рэндж) по градусам Луны.
- **Инструменты рисования:** уровень, трендовая, прямоугольник, овал, стрелка/текст.
- Положение Луны считается локально ([astronomy-engine](https://github.com/cosinekitty/astronomy),
  точность ±1′), интернет для астрологии не нужен.

## Запуск

```bash
node server.js         # → http://localhost:8080
```

Зависимостей нет — только Node.js. Библиотеки уложены локально в `public/vendor/`.

- Если MOEX ISS доступен (обычная локальная машина) — грузятся **живые свечи**
  через прокси `server.js` (он же собирает M5/M15 из минуток, которых ISS не отдаёт).
- Если биржа недоступна (нет сети / запуск в облаке) — включается **демо-режим**
  со сгенерированными свечами, чтобы интерфейс и лунная лента отрисовались.

## Что и где настраивать

Почти всё вынесено в **`public/js/config.js`**:

| Что | Где |
|---|---|
| Тикеры инструментов (ближний контракт) | `LUN.INSTRUMENTS` |
| Цвета 12 знаков | `LUN.SIGNS[].color` |
| **Торговые зоны цикла** (границы в градусах, bias, цвет) | `LUN.MOON_ZONES` |
| Периоды SMA/EMA, настройки VWAP | `LUN.INDICATORS` |

Ориентиры по градусам: `0°` = 0° Овна; 15° Близнецов = **75°**, 15° Весов = **195°**,
15° Козерога = **285°**.

## Структура

```
server.js              Node-сервер: статика + прокси MOEX ISS (+ агрегация M5/M15)
public/
  index.html           разметка и подключение скриптов
  css/style.css        тёмная тема
  js/
    config.js          ← ПУЛЬТ: инструменты, знаки, зоны цикла, индикаторы
    astro.js           положение Луны (долгота → знак/градус/зона)
    indicators.js      кастомные индикаторы: MoonSign, MoonCycle, VWAP±σ
    data.js            загрузчик свечей (ISS + демо-фолбэк)
    app.js             сборка терминала и UI
  vendor/              klinecharts, astronomy-engine (локально)
```
