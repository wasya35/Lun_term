# AG-TS — конспект терминала (обзор для обсуждения)

> Астро-ганновская торговая система. Домен ag-ts.ru. Версия на момент конспекта: **v143**.
> Документ самодостаточный — можно давать сторонним ИИ для обсуждения.
> Философия: **исследовательский терминал**, не «гоняемся за ценой». Не обещаем доход. Данные и методы для анализа.

---

## 0. Коротко: три слоя анализа цены
Терминал совмещает три независимых слоя, и сила — в их **конфлюэнции** (совпадении):

1. **ГДЕ развернётся** — уровни: Ганн (углы, Sq9, боксы), астро-циклы, VWAP, опционные стены. *Это «карта».*
2. **КТО двигает и КУДА набирает** — позиционирование и поток: физ/юр FUTOI, ОИ по бару, покупатели/продавцы, дисбаланс стакана, концентрация крупняка. *Это «топливо».*
3. **КОГДА подтверждение** — события: мега-алерты (крупняк) с исторической статистикой, астро-события, экспирации. *Это «спусковой крючок».*

Ни один слой не даёт сигнала сам по себе — терминал нужен, чтобы видеть, **совпадают ли карта, топливо и триггер в одной точке**.

## 1. Что это и на чём
- Браузерный торговый терминал на **обычном PHP-хостинге** (без Node/сборки). Весь фронт — статика + PHP-бэкенд.
- Фронт: **ванильный JS** (IIFE-модули, без бандлера), графики — **KLineChart v10** (вендор, локально),
  астрономия — **astronomy.browser** (вендор). Сброс кэша через `?v=NN` в index.html.
- Бэкенд: PHP + **SQLite** (аккаунты, рабочие столы, алерты). `api.php` (прокси данных), `auth.php` (аккаунты), `cron.php` (серверные алерты).
- Сервер стоит на площадке, у которой **есть сетевой доступ к MOEX** (перенесли на `loki`) — это критично для реалтайма.

## 2. Данные: что берём и откуда
- **MOEX ISS** — свечи (через прокси `api.php fn=iss`), опционная доска, история ОИ, справочник контрактов.
- **MOEX AlgoPack** (по подписке, ключ **только на сервере**): микроструктура — FUTOI, TradeStats, OBStats, HI2, MegaAlerts.
  - Реалтайм идёт через **apim.moex.com + Bearer-ключ** (зелёный кружок «онлайн»); при недоступности — фолбэк на публичный `iss.moex.com` (жёлтый «отложенный T−15»); нет связи — серый «демо».
- **Крипта** (Bybit/Binance) и **зарубеж** (Yahoo) через `providers/`.
- `iss-client.js` — клиент ISS/AlgoPack; `data.js` — загрузчик/кэш/дозагрузка; `stream.js` — живой поток активного инструмента.
- Прокси `api.php`: `fn=iss` (whitelist passthrough), `fn=algopack` (сессионный, тянет `futoi/tradestats/obstats/hi2/alerts`), `fn=front` (контракты), кэш + рейт-лимит. Ключ AlgoPack — в `lun_data/pk.php` (закрыто `.htaccess`, в git не попадает, в браузер не отдаётся).

### Контракты и роллы (v137/v143)
- Основная кнопка инструмента (Si, CNY…) — **склейка** непрерывного фьючерса (`stitchContracts`, back-adjust по ликвидности).
- **Активный фронт выбирается по ЛИКВИДНОСТИ** (открытый интерес / объём из marketdata), а не по ближайшей экспирации: в день ролла терминал сразу показывает новый контракт, а не истекающий старый.
- **Выбор контракта вручную** (Инструменты → «📆 Контракт фьючерса»): текущий/следующий/дальний, с метками (Si-12.26), датой экспирации и OI; активный по ликвидности помечен. Выбранный грузится как отдельный инструмент со своей разметкой.

## 3. Аккаунты и синхронизация
- Регистрация/вход (**bcrypt**, сессии), аппрув (владелец — авто-админ).
- **Рабочий стол** (разметка, индикаторы, инструменты, настройки, тема) сохраняется: всегда в localStorage + на сервер (если вошёл) → **кросс-девайс** (комп ↔ телефон ↔ вторая сессия).
- Устойчивость сохранения (v132/v135): guard от затирания разметки пустым столом на старте + **немедленный сброс при закрытии вкладки** (beforeunload/pagehide) — разметка и индикаторы больше не теряются «при следующем открытии».
- **Разметка строго пер-инструмент** (штамп владельца + «дворник» чужих оверлеев).
- **Настройки порогов маркеров — пер-инструмент** (v143): у юаня сотни тыс. контрактов, у золота сотни — хранятся раздельно по коду актива.

## 4. Рисование (overlays.js)
Трендовые, лучи (⨯N пересечений), горизонтали, вертикали (дата), прямоугольники, овал, стрелка, **текст** (редактируемый, фон вкл/выкл), **позиция R:R**, **профиль объёма**.
- **Пресеты Smart Money**: трендовая, поддержка/сопротивление, брейкер-блок, ордер-блок, имбаланс (FVG), дивергенция ↑/↓.
- **Линейка %** (Shift+ЛКМ-протяжка: % и число баров), **Data Window** (O/H/L/C/V/Δ под курсором), рисование **за барами**, притяжка к вершинам/низинам, Ctrl+drag = копия, зеркалирование на экраны с тем же инструментом.
- **Выбор рамкой (лассо, v138)**: Alt+протяжка (или режим) — выбрать сразу несколько перекрытых рисунков (углы Ганна в одной точке) и удалить разом.
- **Меню-мультивыбор (v135)**: большие меню не схлопываются после одного пункта — можно включать несколько индикаторов подряд.

## 5. Индикаторы

### 5.1 Рыночные базовые (indicators.js)
- **VWAP мульти** (день/неделя/месяц/все бары + полосы ±1σ/±2σ), осевая палитра по типу якоря.
- **Объём** (наложен полупрозрачно), **кумулятивная дельта** (по дням, *оценка из OHLC*).
- **ОИ**, **базис к споту** (фьюч−спот регрессией + z), **арбитражный спред**.
- **Опционные уровни** (стены по макс-ОИ страйков нед/мес/кв), **экспирации опционов** (авто-вертикали).

### 5.2 Микроструктура MOEX AlgoPack — ГЛАВНОЕ НОВОЕ (v129–v142)
См. отдельную таблицу в §6. Кратко по кнопкам меню МОЕКС:
- **Физ/Юр на свечах** — позиционирование участников (из FUTOI).
- **Поток физ/юр** (нижняя панель) — приток/отток по лонгу/шорту.
- **ОИ по бару (ΔОИ)** и **Покупатели/Продавцы** — из TradeStats.
- **Концентрация HI2** — крупняк (дневной регистр).
- **Дисбаланс стакана** — стены/поддержка-сопротивление (из OBStats).
- **⚡ Мега-алерты** — аномалии с 90-дневной статистикой (из MegaAlerts).

### 5.3 Астро (astro.js, ts-astro.js, cycle.js, sbc.js, synastry.js, montecarlo.js, markov.js, sviridov.js)
- **Луна в знаках** (лента, деканы 10°, градус цифрой), **аспекты планет к Солнцу**, **полоса «все аспекты всех пар»**.
- **Циклы** (зоны лонг/рэндж/шорт по долготе), **Меркурий-цикл (Маслов)**, **узлы Луны**, **затмения**, **Бредли**, **ретроградности**, **ингрессии**, **астро-события** на цене.
- **Марков-режим**, **Монте-Карло**, **синастрия** (трейдер/биржа/инструмент), **SBC**, авторские методы. Астро-календарь на 90 дней.

### 5.4 Ганн
- **Sq9 (квадрат девятки)** в градусах планет (нормальные цены, ×100, ×10000).
- **Углы 1×1** от разворота (правится угол), **сквоузинг** (цена=время), **Gann Box** + прогнозные боксы, **Gann-свинги**, циклы/ретрейсы.

## 6. Микроструктура AlgoPack: что берём / откуда / куда наносим / что даёт для анализа цены

> Все датасеты — **5-минутные агрегаты по бару** (кроме HI2 — раз в день, и MegaAlerts — поминутно).
> Тиковых данных нет → настоящий footprint/кластер недоступен; работаем с агрегатами.

| Индикатор (меню) | Что берём | Откуда (эндпоинт) | Куда наносим | **Что даёт для анализа цены** |
|---|---|---|---|---|
| **Физ/Юр — стрелки счетов** | Δ числа ЛИЦ (счетов) физ/юр по лонгу/шорту за бар | FUTOI `analyticalproducts/futoi` | стрелки под/над свечой (лица) | Сколько *участников* заходит/выходит. Массовый вход физиков часто = толпа (контр-сигнал); юрики = «умные деньги». Фильтр по числу лиц убирает шум. |
| **Физ/Юр — кружки бид/аск** | Δ КОНТРАКТОВ физ/юр (лонг=бид, шорт=аск) | FUTOI | кружки Ф/Ю под (бид) / над (аск) свечой | *Объём* набора позиций стороной. Крупный юр-бид у уровня = поддержка «умных денег»; юр-аск = давление. Буква тёмно-зелёная при «+» счетах. |
| **Перевес бид/аск (нетто)** | нетто = лонг − шорт (контракты) | FUTOI | ОДИН кружок на доминирующей стороне | Убирает парность (и бид, и аск) — сразу видно, **кто в баре сильнее**. **Золотое кольцо** = перевес ≥ N× порога (крупняк зашёл). |
| **Удельный вес / кольцо концентрации** | контракты / число лиц; малое число лиц | FUTOI | фильтр + кольцо у юр-кружка | Высокий удельный вес = **крупные лоты** (немного счетов двигают объём) = концентрированный капитал = сильнее сигнал. |
| **ОИ по бару (ΔОИ)** | oi_close по бару, разница к предыдущему | TradeStats `algopack/fo/tradestats` | нижняя панель (столбики + уровень ОИ), значение бара под курсором | **Топливо движения.** Цена↑ + ОИ↑ = новые деньги (тренд надёжнее). Цена↑ + ОИ↓ = закрытие шортов/выход (движение выдыхается). |
| **Покупатели/Продавцы** | vol_b / vol_s (агрессор) по бару | TradeStats | нижняя панель (покупатели вверх, продавцы вниз) | **Кто агрессивнее** (бил по рынку). Дивергенция «цена растёт, но агрессивных покупок мало» = слабость движения. |
| **Концентрация HI2** | hhi_* (индекс Херфиндаля участников) | HI2 `algopack/fo/hi2` (раз в день ~18:50) | нижняя панель, дневная ступень-линия | **Регистр крупняка на день**: высоко = рынок двигают немногие крупные игроки (движения резче, «умные деньги» рулят); низко = размазано по толпе. Метрика выбирается (агрессивные/пассивные, нетто-поток…). |
| **Дисбаланс стакана (стены)** | vol_b_l1..l20 vs vol_s_l1..l20, спреды | OBStats `algopack/fo/obstats` | нижняя панель: перевес бидов вверх (поддержка), асков вниз (сопротивление); L1 = стена | **Где плотность заявок.** Перекос в биды у уровня = поддержка/магнит снизу; в аски = крышка сверху. L1-стена = ближайший барьер. Ближайшее к «айсбергам», что дают агрегаты. |
| **⚡ Мега-алерты (крупняк)** | аномалии: крупные покупки/продажи, экстремумы цены/ОИ/нетто-объёма + 90-дн. статистика | MegaAlerts `algopack/fo/alerts` (поминутно, весь рынок → фильтр к инструменту) | маркеры на свечах (B/S/N/▲▼/O/V); клик → тултип | **Триггер с историческим edge.** Клик по маркеру: «после таких сигналов за 90 дней цена в среднем росла +X% в N случаях / падала −Y%» через 5/15/30/60 мин + объём в сигнале. Даёт **вероятность**, а не просто факт. |
| **Данные FUTOI (окно)** | все снимки физ/юр по бару и накопительно | FUTOI | плавающее окно с таблицей и календарём | Точные цифры позиций; **клик по строке подсвечивает бар** на графике (жёлтая полоса). |

**Пороги** у каждого индикатора маркеров — свои **на каждый ТФ** (масштаб бара) и **на каждый инструмент** (у юаня сотни тыс., у золота сотни): «портянка» в меню правит текущий инструмент, значения запоминаются; пока не заполнено — авто-масштаб.

## 7. Как это читать вместе (методология «дойдёт ли до ОПР»)

Область принятия решений (ОПР) = уровень из слоя 1 (Ганн/астро/VWAP/опционная стена). Вопрос: **дойдёт ли цена и развернётся ли?** Слои 2–3 отвечают.

**Сценарий «разворот у уровня снизу» (ищем лонг):**
1. Цена подходит к уровню (угол Ганна / Sq9 / нижняя опционная стена / VWAP−2σ).
2. **ОИ**: на подходе ОИ падает (шорты выдыхаются) или у уровня резко растёт (набор лонгов) — топливо для отбоя.
3. **Физ/Юр**: юр-бид кружок (тем более с золотым кольцом = крупняк) у уровня — умные деньги набирают лонг.
4. **Стакан**: перевес в биды, L1-стена снизу — заявки держат.
5. **Покупатели/Продавцы**: агрессивные покупки нарастают.
6. **HI2**: высокая концентрация = крупный игрок в деле.
7. **Мега-алерт**: «крупная покупка» / «net_vol+» с историей роста после сигнала — триггер.
→ Совпало 4–5 пунктов в одной точке = **высоко-вероятная ОПР**. Совпал только уровень без топлива — цена может не дойти/проколоть.

**Обратное (уровень сверху, ищем шорт):** зеркально — юр-аск, перевес асков, продавцы-агрессоры, «крупная продача»/«net_vol−», ОИ-подтверждение.

**Красные флаги (не входить):** к уровню идёт **толпа физиков** (массовые стрелки счетов) при слабом ОИ и низкой концентрации — типичный вынос толпы; агрессивный поток в одну сторону при падающем ОИ = закрытие, а не набор.

**Астро-таймингом** проверяем момент: ингрессия/аспект/затмение/цикловая зона рядом с подходом к ОПР усиливает ставку на разворот именно здесь и сейчас.

## 10. Технические ограничения (важно)
- Хостинг обычный PHP — **нет Node/воркеров**; тяжёлое считаем на клиенте.
- **Ключи/подписки — только на сервере**, в браузер не отдаём; данные по подписке не перераздаём публично.
- KLineChart: оверлеи на верхнем canvas; крестик отдаёт {x,y,paneId} (бар считаем сами); кастомный `draw` **не** вызывается на ховер (обновляем через `overrideIndicator`).
- **Тиковых данных нет** (AlgoPack = 5-мин агрегаты, HI2 = раз в день, alerts = поминутно) → настоящий footprint/айсберги недоступны; «стены» и «поглощение» выводим из агрегатов стакана.
