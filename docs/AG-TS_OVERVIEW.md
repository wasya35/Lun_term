# AG-TS — конспект терминала (обзор для обсуждения)

> Астро-ганновская торговая система. Домен ag-ts.ru. Версия на момент конспекта: **v120**.
> Документ самодостаточный — можно давать сторонним ИИ для обсуждения.
> Философия: **исследовательский терминал**, не «гоняемся за ценой». Не обещаем доход. Данные и методы для анализа.

## 1. Что это и на чём
- Браузерный торговый терминал на **обычном PHP-хостинге** (без Node/сборки). Весь фронт — статика + PHP-бэкенд.
- Фронт: **ванильный JS** (IIFE-модули, без бандлера), графики — **KLineChart v10** (вендор, локально),
  астрономия — **astronomy.browser** (вендор). Сброс кэша через `?v=NN` в index.html.
- Бэкенд: PHP + **SQLite** (аккаунты, рабочие столы, алерты). `api.php` (прокси данных), `auth.php` (аккаунты),
  `cron.php` (серверные алерты).
- Данные: **MOEX ISS** (свечи через прокси api.php `fn=iss`, FUTOI, опционная доска), крипта (Bybit/Binance),
  Yahoo (зарубеж). Живой поток (стрим) для активного инструмента.

## 2. Аккаунты и синхронизация
- Регистрация/вход, **bcrypt**, сессии, система **подтверждения** (владелец — авто-админ, остальные ждут аппрув).
- **Рабочий стол** (разметка, индикаторы, инструменты, тема) сохраняется: всегда в localStorage + на сервер
  (если вошёл) → **кросс-девайс синхронизация** (комп ↔ телефон ↔ вторая сессия).
- **Разметка строго пер-инструмент** (штамп владельца + «дворник» чужих оверлеев) — не протекает между инструментами.
- Админ-панель: список юзеров, аппрув/бан.

## 3. Данные и провайдеры
- `iss-client.js` — MOEX ISS: свечи, склейка непрерывных фьючерсов (роллы), FUTOI (физ/юр long/short),
  опционы (страйки/тип/ОИ/экспирация), история ОИ.
- `providers/` — base / crypto (Bybit, Binance) / yahoo.
- `data.js` — загрузчик, кэш, дозагрузка истории; `stream.js` — живой поток (страж целостности: чужой бар не попадёт).
- Прокси `api.php`: `fn=iss` (whitelisted passthrough на iss.moex.com, кэш + рейт-лимит).

## 4. Инструменты рисования (overlays.js)
Трендовые, лучи (⨯N пересечений), горизонтали, **вертикали (дата)**, прямоугольники, **текст** (редактируемый,
фон вкл/выкл), **позиция R:R** (вход→цель, риск/приз), **профиль объёма** (полупрозрачный).
- **Типы линий (пресеты Smart Money)**: трендовая, поддержка, сопротивление, брейкер-блок, ордер-блок,
  имбаланс (FVG), дивергенция ↑/↓ — цвет/толщина/пунктир/заливка на любой инструмент.
- **Линейка %** (протяжка ЛКМ: % изменения + число баров), **Data Window** (O/H/L/C/V/Δ под курсором),
  **рисование ЗА барами** (галочка: разметка под свечи), притяжка к вершинам/низинам, Ctrl+drag = копия,
  копипейст, зеркалирование на другие экраны с тем же инструментом.
- Сворачиваемая легенда (тикер ▼ → полные данные бара по клику).

## 5. Индикаторы и панели (indicators.js)
### Рыночные
- **VWAP мульти** (день/неделя/месяц/все бары + полосы отклонений), осевая палитра по типу якоря.
- **Объём** — наложен на ценовую панель полупрозрачно (за ним виден график).
- **Кумулятивная дельта** — по дням (сброс внутри дня, сегменты как в ATAS/TigerTrade). *Пока оценка из OHLC.*
- **FUTOI-стрелки** — массовое открытие физлиц в свече (порог настраивается).
- **Опционные уровни** — стены по макс-ОИ страйков (нед/мес/квартал), от начала серии.
- **Экспирации опционов** — авто-вертикали с датой/временем (нед/мес/кв), прошлые и будущие.
- **ОИ**, **базис к споту** (фьюч−спот регрессией + z), **арбитражный спред**.

### Астро (astro.js, ts-astro.js, cycle.js, sbc.js, synastry.js, montecarlo.js, markov.js, sviridov.js)
- **Луна в знаках** (лента), **аспекты планет к Солнцу** (по планетам), **полоса «все аспекты всех пар»**
  (цветные риски + подписи символами планет/аспекта, с исчезновением при тесноте).
- **Циклы** (зоны лонг/рэндж/шорт по долготе), **Меркурий-цикл (Маслов)**, **узлы Луны**, **затмения** (вертикали),
  **Бредли**, **ретроградности**, **ингрессии**, **астро-события** на цене.
- **Марков-режим** (лента + сигнальная панель + матрица), **Монте-Карло**, **синастрия** (карты трейдера/биржи/инструмента),
  **SBC**, авторские методы (sviridov.js). Астро-календарь (ингрессии/аспекты/ретро/фазы/затмения на 90 дней).

### Ганн (в indicators.js + app.js)
- **Sq9 (квадрат девятки)** в градусах планет — отдельные кнопки для нормальных цен, цен 1–100 (×100), <0.01 (×10000).
- **Гановские углы 1×1** от разворота (правится угол), **сквоузинг** (цена=время), **Gann Box** + прогнозные боксы
  по диагонали, **Gann-свинги** (1/2/3-баровые, за барами), гановские циклы/ретрейсы.

## 6. Экраны, симуляция, бэктест, алерты
- **Мульти-экран** (несколько ячеек, синхронизация курсора/масштаба, зеркалирование разметки), раскладки.
- **Симуляция/реплей** (шаг вперёд, открытие лонг/шорт по цене, авто-закрытие по TP/SL, кривая доходности в R).
- **Бэктест-движок** (backtest.js): прогон стратегий на истории, склейка непрерывных фьючерсов, результаты/статистика.
- **Алерты** (alerts): ценовые и астро, e-mail/Telegram, проверка на сервере (`cron.php`) — терминал можно закрыть.
- **Новости** (news.js) с меткой настроения по инструменту; исследования (research.js).

## 7. UI/прочее
- Верхнее меню (Инструменты/ТФ/Период/Индикаторы/Рисование/Астро/Ганн/Личные данные/Симуляция/Настройки/Алерты/Экраны).
- Тема тёмная/светлая, тип свечей, кружок подключения в меню, поиск/избранное инструментов.
- Дисклеймер «не инвестсовет» (pravila.html). Кэш-бастинг версий.

## 8. Текущее состояние методов (со слов владельца)
- **Sq9**: красиво и рабоче для **Si**; для других фьючерсов/акций надо **алгоритмизировать** авто-подбор якорей.
- **VWAP нед/мес**: цена работает, но нужна **подкрутка VSA**.
- **Аспекты все-против-всех**: дают толчок.
- **Smart money разметка**: рабочий плюс.
- **Углы Ганна**: рабочие для Si, но **последнее время цена не всегда доходит до ОПР** (области принятия решений).

## 9. Куда движемся (интеграция данных)
Подключён **MOEX AlgoPack** (данные микроструктуры: FUTOI, TradeStats, OBStats, OrderStats, HI2, MegaAlerts) +
опционная доска. Подробно — в `docs/ALGOPACK_CLUSTER.md` (разбор терминала Cluster, что берём, дорожная карта Э0–Э6,
стратегии и «скор ОПР»). Идея: наложить **позиционирование крупняка и опционные магниты (GEX/MaxPain)** на наши
**астро/ганн/Sq9-уровни** → объяснять «дойдёт ли цена до ОПР» и считать конфлюэнцию.

## 10. Технические ограничения (важно для обсуждения)
- Хостинг обычный PHP — **нет Node/воркеров**; тяжёлое считаем на клиенте или редким кроном.
- **Ключи/подписки — только на сервере** (прокси), в браузер не отдаём; данные по подписке не перераздаём публично.
- KLineChart-специфика: оверлеи на отдельном верхнем canvas; крестик отдаёт только {x,y,paneId} (бар считаем сами).
- Тиковых данных нет (AlgoPack = 5-мин агрегаты) → настоящий footprint недоступен, остаётся свой профиль объёма.
