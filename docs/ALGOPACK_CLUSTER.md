# AlgoPack + разбор терминала Cluster (cluster-search.ru)

> Конспект для будущей интеграции MOEX AlgoPack в AG-TS. Чистые заметки, не ТЗ.
> Собрано по скринам закрытого терминала Cluster (использует те же данные) + доке AlgoPack.
> Пока НИЧЕГО не строим — это память проекта, чтобы стартовать, когда скажем «делаем».

## 0. Ключевой принцип
AlgoPack = аналитические данные MOEX, **5-минутные агрегаты** (не тик), рынки `eq` (акции),
`fo` (фьючерсы), `fx` (валюта). Доступ по **API-ключу** через `apim.moex.com/iss/datashop/algopack/...`
(или MOEX Passport через `iss.moex.com/iss/datashop/algopack/...`).
**🔑 Ключ живёт ТОЛЬКО на сервере** (прокси в api.php, как fn=iss). В браузер не отдаём.
Лицензия: перераздавать публично нельзя — фичи прячем за логином.

## 1. Наборы данных AlgoPack (что вообще есть)
| Набор | Рынок | Ключевые поля |

| **OBStats** | eq/fo/fx | число ценовых уровней, спред min/max/avg, ликвидность, дисбаланс бид/аск |
| **FUTOI** | fo | pos_long/pos_short, pos_long_num/pos_short_num — по физ/юр лицам |
| **Futures TradeStats** (доп.) | fo | oi_open/high/low/close (ОИ в свече!), im (гарант. обеспечение), sec_pr_* (цена БА) |

## 3. Лист «Cluster» (footprint + маркеры)
Вкладки: Кластеры · Счета · Опционы · Ф/Ю. ТФ 5M. «Загружено N баров, K уровней».

### 3.1 Счета (счета физлиц)
Кнопки: `Ф.лонг +` (открытие лонга физиками), `Ф.лонг −` (закрытие), `Ф.шорт +`, `Ф.шорт −`.
→ **Источник: FUTOI дельта** (изменение pos_long/pos_short физиков за 5 мин).

### 3.2 Опционы (наложение на график)
`Опц. уровни` (стены кол/пут по ОИ), `GEX`, выбор серии (M — месяц, W — неделя),
`Хедж +/−`, `MaxPain`, `PCR`. Слева метки: «кол 87500 V870 · 15.10», «MaxPain 86000 · PCR 0.932»,
«пут 85000/84000». → Источник: опц. доска (+ греки для GEX).

### 3.3 Ф/Ю (bid/ask по типам лиц) — «цимес»
Кружки на свече: 🟢 `Ф/Ю bid` (агрессивно покупали), 🔴 `Ф/Ю ask` (продавали);
`+` открытие, `−` закрытие; «не определено» (?) — не разложилось. Число = нетто контрактов.
→ **Источник: эвристика** = агрессор bid/ask (TradeStats vol_b/vol_s) × изменение позиций
физ/юр (FUTOI). Разрез агрессора по типу счёта в чистом TradeStats обычно НЕТ → выводим моделью.
(Проверить: не даёт ли наш тариф готовый разрез.)

### 3.4 «ОТС объём» (нижняя гистограмма ±50k) — внебиржевой/нетто объём (уточнить).
Верхние счётчики Σ/S/iS/B/iB — агрегаты по показанным маркерам (косметика).

### 3.5 Настоящий footprint (Кластеры, «739 уровней»)
Объём по каждой цене внутри свечи → **нужны тиковые данные / полный лог сделок MOEX**,
это НЕ 5-мин AlgoPack, а отдельный тяжёлый фид. У нас есть свой профиль объёма (проще).

## 4. Лист «F&Y» (SI Open Interest Analyzer) — самая сильная аналитика
Полный разбор **FUTOI**. 4 ряда снимками ~5 мин, каждый = кол-во позиций + кол-во лиц:
`Ф.Лонг · Ф.Шорт · Ю.Лонг · Ю.Шорт`. Всё остальное — арифметика дельт (Δ к прошлому снимку и к базе=вчера).

### Пары контрагентов (главное)
ΣЛонги ≡ ΣШорты (баланс ≈0, в таблице «ΣЛ−ΣШ = −3» — контроль целостности). Δ раскрывает, кто у кого перекупил:
- 🟢 **Физик Лонг / Юрик Шорт** — физики набрали лонг, юрики шорт;
- 🔴 **Физик Шорт / Юрик Лонг** — наоборот;
- 🟠 **Юрик vs Юрик** — крупный против крупного.

Маркеры: зел.▽ снизу = Ф.Лонг, красн.▽ сверху = Ф.Шорт, оранж.● = Юрик vs Юрик; число = объём перекладки.

### Сигналы (лента справа)
Крупная/дисбалансная перекладка → флаг с %. Пример 12:45 на переломе: `Физик Шорт 1171 / Юрик Лонг 8452`
(юрики агрессивно в лонг против физиков). Это «кто с кем кому торговал» + перевес/настроение.

### Вкладка «Данные» (таблица)
Колонки: Ф.Лонг / Ф.Шорт / Ю.Лонг / Ю.Шорт. Строки:
- Кол-во позиций (абс. ОИ); Оперативно к пред.закрытию (Δ vs вчера);
- **Кол-во лиц** (физики тысячи ~9864, юрики сотни ~357);
- **Средний контракт/счёт** = позиции/лица (физик ~119, юрик ~14030 → масштаб игрока, юрики=крупняк);
- Изм. средней позиции/лицо; Баланс ΣЛ−ΣШ.
- Чистый ДОИ: перераспределение Ф→Ю / чистый набор. Оперативный снимок MOEX HH:MM, база Δ = пред. закрытие.
- Правая колонка-поток: те же 4 Δ каждые 5 мин накопительно → тренд позиционирования
  (пример: 11:15→13:10 рос Ю.Шорт → слом тренда вниз).

→ **Воспроизводимо 100% из AlgoPack FUTOI.** Нюанс: снимок ~5 мин, мелкое расхождение баланса — норма MOEX.

## 5. Лист «Si Option» (V3: Sparklines) — опционный деск
Снапшоты опц. доски в архив (у серии Si-9.26 — 16 369 снапшотов; истёкшие серии тоже хранятся).

- **Таблица цепочки** по страйкам: `Call ОИ · ΔCall · спарклайн Call · Страйк · спарклайн Put · ΔPut · Put ОИ`.
  Δ — изм. ОИ страйка с прошлого снапшота; спарклайн — внутридневная история набора ОИ. ATM подсвечен.
- **Агрегаты**: PCR ОИ, PCR объём, Max Pain, ATM, ΣОИ пут/колл, до эксп. (дней).
- **Визуал**: профиль ОИ по страйкам (PUT красн / CALL зел) + вертикали Max Pain, **GEX-магнит**
  (куда гамма тянет цену), **GEX flip** (смена режима: выше — гасит, ниже — ускоряет), **Skew** (перекос IV), цена Si.
- **Визуал ист.**: ползунок по времени — реплей наполнения страйков и хода цены между ними; тултип по страйку (CALL/PUT OI).
- История серий: фильтр Все/Квартальные/Месячные/Недельные; хранят снапшоты по каждой серии.
- Ещё: ДОИ день, IV/GEX, Крупные заявки, Заявки на свече.

### 5.1 «ДОИ день» — нетто-профиль ΔОИ за торговый день
Столбики по страйкам: **вверх — ДОБАВИЛИ позиций** (новый интерес), **вниз — ЗАКРЫЛИ** (интерес ушёл).
Зелёные = коллы, красные = путы, пунктир = цена Si. Внизу Σ коллы / Σ путы. Дата-степпер по дням.
→ **Источник: биржевое поле `OICHANGE`** — точное изменение ОИ от закрытия пред. дня (НЕ выводим, даётся готовым!).
Читается: где реально прибавили/сняли интерес по страйкам сегодня → куда смещаются стены.

### 5.2 «IV / Skew / GEX» — улыбка волатильности и гамма
Важно: **готовую IV биржа НЕ отдаёт** → терминал считает IV по **Black-76 из середины bid/offer** каждого опциона,
из IV — греки (гамма). Метрики сверху: ATM IV (15.66%), Skew (−0.72 п.), Net GEX, **Gamma flip** (77 925).
- **Улыбка волатильности**: IV по страйкам (зел=коллы, красн=путы, пунктир=цена). Метки пут/колл с IV.
- **GEX-профиль**: столбик вверх — хеджеры **ГАСЯТ** движение на уровне (магнит), вниз — **РАЗГОНЯЮТ** (ускоритель);
  янтарный пунктир = gamma flip.

Смысловые определения (из тултипов терминала — сохранить, отличная методичка):
- **IV** — ожидаемый размах, «зашитый» в цену опциона (% годовых). Рост IV при стоячей цене = рынок ждёт сильного движения.
- **Skew** — насколько путы дороже коллов на равном удалении (в пунктах IV). Рост skew = крупные деньги платят за
  защиту от падения → медвежий сигнал, часто ДО движения цены; падение skew = страх уходит.
- **GEX (гамма-экспозиция)** — сколько фьючерсов хеджерам докупить/продать при движении цены на 1 пункт.
  Σ GEX > 0 → хеджеры торгуют ПРОТИВ движения (день боковой, уровни-магниты); < 0 → ПО движению (ускоряется).
- **Gamma flip** — цена, где режим меняется: выше — рынок «вязкий», ниже — «скользкий» (или наоборот — по знаку профиля).

→ **Источник:** опц. доска (bid/offer по опционам) + расчёт **Black-76** (IV solver + греки) у нас.

→ **Итого по Si Option:** нужно (1) серверный крон, пишущий снапшот доски (ОИ, bid/offer, OICHANGE) каждые N мин в базу;
(2) свой **Black-76** (Ньютон-Рафсон по IV + гамма/дельта/вега) для GEX/Skew/улыбки. Это апгрейд нашего OptionLevels до полного деска.

## 7. Наш угол (зачем это нам, а не «ещё один Cluster»)
Позиционирование крупняка + опционные магниты **накладываем на астро/ганн-уровни**:
- «на уровне Sq9/угле Ганна юрики массово в лонг против физиков» = подтверждение уровня;
- GEX-магнит рядом с ганн-уровнем = двойной магнит;
- слом тренда позиционирования (F&Y поток) у астро-даты = сигнал.
Мы не гоняемся за ценой — показываем, кто и как позиционируется у наших уровней.

## 9. Выводы: что реально берём через API и добавляем в AG-TS
- **Всё «мясо» — из двух источников**: (а) AlgoPack FUTOI/TradeStats/OBStats/OrderStats (ключ, apim),
  (б) опционная доска MOEX (ОИ, bid/offer, **OICHANGE** — точный ΔОИ; бесплатно, без ключа).
- **Готовой IV нет** → нужен свой Black-76 (IV solver + греки). Это единственная «математика», всё остальное — агрегация.
- **История/реплей/деск требуют серверного архива** (крон пишет снапшоты в SQLite) — иначе только «сейчас».
- **Наш дифференциатор** (не клон Cluster): накладываем позиционирование крупняка (F&Y) и опционные
  магниты (GEX/MaxPain/стены) на **астро/ганн/Sq9-уровни** и даты. Cluster этого не умеет — это наша фишка.
- **Тик/footprint не берём** (нет в AlgoPack) — у нас остаётся свой профиль объёма.

## 10. Архитектура интеграции
**Сервер (PHP, у нас уже есть api.php/cron.php/SQLite):**
- `api.php?fn=algopack&ds=<futoi|tradestats|obstats|orderstats>&secid=...` — прокси, подставляет ключ
  (из ENV/файла вне git), кэш + рейт-лимит, отдаёт JSON. Ключ в браузер НЕ уходит.
- `cron.php`: снапшоттер каждые ~5 мин пишет в БД: (1) опц. доску (страйк, тип, ОИ, bid/ask, OICHANGE),
  (2) FUTOI (Ф/Ю long/short позиции и лица). Плюс дневной агрегат. Живёт даже с закрытым браузером.
- `fn=optsnap` / `fn=futoi_hist` — чтение истории снапшотов для реплея/потока.

**Клиент (JS, вендор-стиль без сборки):**
- `algopack-client.js` — тянет с нашего прокси (FUTOI/tradestats/obstats).
- `black76.js` — IV по Ньютону-Рафсону из mid bid/offer + греки (gamma/delta/vega) → GEX/Skew/улыбка.
- индикаторы/панели: позиционирование Ф/Ю, реальная дельта, ОИ в свече, опционный деск (модал/лист),
  GEX-магнит/flip как уровни-магниты на графике, OBStats-панель, алерты.

## 11. Дорожная карта (этапы, от ценного к нишевому)
**Э0 · Инфраструктура + ключ.** `fn=algopack` прокси (ключ на сервере) + 1 проверочный запрос →
закрываем вопросы п.8 (авторизация, рынки, история, live, есть ли разрез агрессора, IV). *Без этого нельзя дальше.*

**Э1 · F&Y — позиционирование физ/юр (самое «наше»).** FUTOI: 4 ряда, Δ к прошлому снимку и к базе,
пары контрагентов (Ф-лонг/Ю-шорт и т.д.), средний контракт/счёт, поток, сигналы на дисбалансе.
Панель «Данные» + маркеры на свече + **наложение на астро/ганн-уровни**. Пер-инструмент, в рабочий стол.

**Э2 · Опционный деск, базовый (без крона).** Из живой доски: цепочка, MaxPain, PCR, ATM, ΣOI,
профиль ОИ по страйкам (Визуал), стены. Апгрейд текущего OptionLevels. Даёт мгновенную пользу.

**Э3 · Серверный архив снапшотов.** Крон пишет доску (с OICHANGE) и FUTOI в БД. Открывает:
**ДОИ день** (точный ΔОИ по страйкам), **Визуал-ист** (реплей наполнения страйков + ход цены),
**F&Y поток из истории** (а не только «сейчас»).

**Э4 · IV / греки (Black-76).** Улыбка волатильности, Skew, **GEX-профиль**, **GEX-магнит**, **Gamma flip**.
Магнит/flip выносим на график как уровни рядом с ганн/Sq9 → «двойной магнит». Skew как ранний мед./быч. сигнал.

**Э5 · Реальная дельта + ОИ в свече.** TradeStats vol_b/vol_s → апгрейд CumDelta (настоящая дельта агрессоров);
futures tradestats oi_* → ОИ прямо в свече.

**Э6 · Стакан/поток/алерты (по вкусу).** OBStats (спред/ликвидность/дисбаланс бид-аск),
OrderStats (спофинг — всплеск снятий), MegaAlerts → в наши серверные алерты, HI2 (концентрация потока).

**Зависимости:** Э0 → всё; Э3 → (ДОИ день, Визуал-ист, история F&Y); Э4 → нужен Э3 (или живой bid/offer) + Black-76.
Э1/Э2/Э5 независимы и дают пользу сразу.

## 12. Стратегии и конфлюэнция (как из данных делать сигналы)
Философия: не гоняемся за ценой — показываем ПОЗИЦИОНИРОВАНИЕ и структуру, накладываем на астро/ганн-уровни,
и превращаем интуицию в **измеримую вероятность** (у нас есть бэктест-движок).

### 12.1 «Толпа-трэп» — контрарианский сигнал по физикам (FUTOI)
Наблюдение (из терминала Cluster): физики — «дурные деньги». Если физики массово набрали ЛОНГ:
их либо мгновенно опрокидывают вниз, либо цена **приходит к ним через 3–10 дней** (реже дольше) и «выбивает».
С массовым ШОРТОМ физиков — зеркально (цена идёт вверх к ним).
- **Сигнал**: перекос физиков = нетто-позиция физ (лонг−шорт) как **z-score** или **% от общего ОИ**; экстремум → «зона разворота».
- **Сетап «цена ещё не против них»**: толпа набрала, но цена не сходила к их средней → потенциал есть.
- **Средняя цена набора толпы** ≈ VWAP периода, когда рос их ОИ → цель, куда цену тянет «выбить».
- **Подтверждение**: физики набирают ПРОТИВ юриков (юрики с противоположной стороны = умные деньги).
- **Как мерить (бэктест)**: при |z| физиков > порога — через сколько баров/дней и с какой вероятностью цена
  доходит до их средней / разворачивается. Гипотеза 3–10 дней → конкретная цифра по истории FUTOI+цены.

### 12.2 GEX-фильтр к Ганну / ОПР (почему цена не доходит до области решений)
Проблема: последнее время цена не всегда доходит до ганн-ОПР. Причина часто — **опционный магнит на пути**.
- **Σ GEX > 0 (положит. гамма)** → хеджеры гасят движения, цена залипает у **GEX-магнита / MaxPain**,
  и **не долетает** до дальней ОПР. Если магнит стоит РАНЬШЕ уровня — тормозит на нём.
- **Σ GEX < 0 (ниже gamma-flip)** → рынок «скользкий», движения ускоряются → **до дальней ОПР долетает**.
- **Правило**: ганн-ОПР достижима, если на пути нет магнита и гамма отрицательная; иначе промежуточная цель = **магнит**.
- Это даёт Ганну и объяснение «почему не дошло», и промежуточный таргет.

### 12.3 Skew как ранний сигнал настроения
Рост **skew** (путы дороже коллов) = крупные деньги платят за защиту от падения = **медвежий сигнал,
часто ДО движения цены**. Падение skew = страх уходит (бычий). Смотрим у уровней и перед аспект-датами.

### 12.4 VSA на реальной дельте
VWAP нед/мес + VSA у нас «на глаз». TradeStats `vol_b/vol_s` = настоящий агрессор → усилие/результат по-настоящему:
узкий бар на большом агрессивном объёме без движения = поглощение (разворот); широкий на слабом = вакуум.

### 12.5 Скор ОПР (конфлюэнция) — главный синтез
Отдельный сигнал = «толчок». Сила — в совпадении на ОДНОМ уровне. Считаем скор 0–100 из факторов:
- ганн/Sq9/VWAP-уровень рядом (вес);
- GEX-магнит / стена ОИ на этом уровне;
- экстремум позиционирования толпы (физики против юриков);
- дата астро-аспекта / ингрессии рядом по времени;
- реакция дельты/VSA при подходе.
Много факторов совпало → сильная **область принятия решений**. Это наш продукт, которого нет у Cluster
(нет астро/Ганна) и не было у нас (не было потока). Каждый вес — калибруется бэктестом.

### 12.6 Что усиливает каждый наш метод (сводка)
| Метод AG-TS | Что добавляет поток AlgoPack |
|---|---|
| Sq9 уровни | кто позиционирован у уровня (подтверждение); авто-Sq9 для акций — наша алгоритмика, не API |
| VWAP нед/мес + VSA | реальная дельта агрессора (vol_b/vol_s) → настоящий VSA |
| Аспекты все-против-всех | наложить поток/развороты толпы на даты аспектов (корреляция) |
| Smart money разметка | спофинг (OrderStats) + дисбаланс (OBStats) + позиции юриков = реальный след крупняка |
| Углы Ганна / ОПР | GEX-магнит/гамма-режим: дойдёт ли цена до ОПР + промежуточная цель |

## 13. ОФИЦИАЛЬНЫЙ РЕФЕРЕНС (github.com/moexalgo/algopack-skills) — точные эндпоинты/поля
Источник: официальный репозиторий MOEX «algopack-skills» (Agent Skills). Хост **`https://apim.moex.com/iss`**,
заголовок **`Authorization: Bearer <APIKEY>`**. Публичный (с задержкой) — `https://iss.moex.com/iss` без ключа.
Формат ISS: блоки `{columns:[...], data:[[...]]}` → нормализуем в объекты. Пагинация: `start` += кол-во строк,
пока блок не пуст (у SuperCandles **кап 1000 строк** → пагинация обязательна). Форматы: `.json` / `.csv`.

### ⚠️ ТАРИФЫ (критично для нас!)
- **Стартовый / Starter** (бесплатный API-токен): свечи/сделки с задержкой 15 мин; **FUTOI с задержкой T−15 ДНЕЙ**;
  SuperCandles/MegaAlerts/HI2 — планово T−1 день (не гарантировано). → для ЖИВОЙ торговли FUTOI бесполезен, только research/бэктест.
- **Promo** (платный): FUTOI/стакан/свечи/сделки **онлайн** + SuperCandles + MegaAlerts + HI2 + календарь.
- Ошибки: 401 (ключ), 403 (нет подписки/не тот хост/вне тарифа), 429 (рейт-лимит) → бэкофф, не долбить.

### FUTOI — ПУТЬ ИНОЙ, не под datashop/algopack!
`/iss/analyticalproducts/futoi/securities.json?date=YYYY-MM-DD`  (все)
`/iss/analyticalproducts/futoi/securities/{ticker}.json?from=&till=`  (один; **ticker = БАЗОВЫЙ АКТИВ, напр. `Si`**, не `SiU6`)
Блок `futoi`. Снимки 5 мин, история с 2020. Поля: `tradedate, tradetime, ticker, clgroup(FIZ|YUR), pos(=long−short),
pos_long, pos_short, pos_long_num, pos_short_num, sess_id, seqnum, systime`. Агрегат по всем активным сериям Si.

### SuperCandles: TradeStats / OrderStats / OBStats (`{eq|fo|fx}`)
`/iss/datashop/algopack/{mkt}/{tradestats|orderstats|obstats}.json?date=YYYY-MM-DD[&latest=1]`  (все)
`/iss/datashop/algopack/{mkt}/{...}/{ticker}.json?from=&till=[&latest=1&start=N]`  (один; ticker = secid контракта, напр. `SiU6`)
Блок `data`. 5-мин, история с 2020, публикация через неск. секунд после закрытия 5-минутки.
- **TradeStats**: `tradedate,tradetime,secid, pr_open/high/low/close, pr_vwap, pr_vwap_b, pr_vwap_s, pr_change, pr_std,
  trades/trades_b/trades_s, vol/vol_b/vol_s, val/val_b/val_s, disb(дисбаланс)`. **FO доп.**: `asset_code, im, oi_open/high/low/close`.
- **OrderStats**: `put_orders(_b/_s), put_vol(_b/_s), put_val(_b/_s), put_vwap_b/s, cancel_orders(_b/_s), cancel_vol(_b/_s),
  cancel_val(_b/_s), cancel_vwap_b/s`. Много put+cancel = «рисованная» ликвидность (спофинг).
- **OBStats**: `spread_bbo/lv10/1mio, levels_b/s, vol_b/s, val_b/s, imbalance_vol(_bbo)/imbalance_val(_bbo), vwap_b/s(_1mio)`.
  FO/FX доп.: `mid_price, micro_price, spread_l1..l20, vol_b_l1..l20` (глубина стакана по уровням).

### HI2 (концентрация)  `/iss/datashop/algopack/{mkt}/hi2[/{ticker}].json?date|from&till`
Блок `data`. Ежедневно. Поля: `tradedate,tradetime,secid,metric,value,reference,systime`.
metric: `hhi_volume, hhi_buy/sell, hhi_netflow_buy/sell, hhi_passive, hhi_aggressive(_buy/_sell)`. Бэнды: <1500 / 1500–2500 / >2500.

### MegaAlerts  `/iss/datashop/algopack/{eq|fo}/alerts[/{ticker}].json?date|from&till`
Блок `data`. Поля: `tradedate,tradetime,secid,alert_type,threshold,value,reference(JSON),systime`.
alert_type: `vol_(b|s)_99_9_pctl, vol_99_9_pctl, net_vol_99_9_pctl±, pr_change_99_9_pctl±, pr_(high_max|low_min)` и *_max/_min.
`reference` = пост-алерт статистика за окно: для `m_5/m_15/m_30/h_1` массив [ср.рост%, ср.паден%, N рост, N паден, ср.всего%] +
`vol_b/vol_s`. Это встроенный мини-бэктест «что было после похожего сигнала».

### Свечи/стакан/сделки под ключом (онлайн на Promo)
`/iss/engines/{stock|futures|currency}/markets/{shares|forts|selt}/boards/{TQBR|RFUD|CETS}/securities/{ticker}/{candles|trades|orderbook}.json`
Свечи: `open/high/low/close/volume/value/begin/end`, `interval=1|10|60|24|7|31`, пагинация `start`. Сделки: `BUYSELL, PRICE, QUANTITY`.

### Питон-библиотека (альтернатива REST)
`pip install "moexalgo[dataframe]" python-dotenv`; `session.TOKEN = APIKEY` (переключает базу на apim + Bearer);
`Market("EQ").obstats(date=...)`, `Ticker(...)`. Удобно для бэктест-скриптов/крона на шлюзе, но для терминала мы всё равно
дергаем REST через нашу проксю.

### Правки к разделам выше (по факту из офиц. доки)
- FUTOI берём с `analyticalproducts/futoi` (НЕ `datashop/algopack/fo/futoi` — такого нет), ticker = базовый актив (`Si`).
- SuperCandles ticker = secid контракта (`SiU6`); ответы капятся на 1000 строк → пагинация `start`.
- Готовой IV/греков в доске нет (подтверждено) → Black-76 у нас. Опц. доска — по-прежнему `engines/futures/markets/options`.
