# AlgoPack + разбор терминала Cluster (cluster-search.ru)

> Конспект для будущей интеграции MOEX AlgoPack в AG-TS. Чистые заметки, не ТЗ.
> Собрано по скринам закрытого терминала Cluster (использует те же данные) + доке AlgoPack.
> Пока НИЧЕГО не строим — это память проекта, чтобы стартовать, когда скажем «делаем».

## 0. Ключевой принцип
AlgoPack = аналитические данные MOEX, **5-минутные агрегаты** (не тик), рынки `eq` (акции),
`fo` (фьючерсы), `fx` (валюта). Доступ по **API-ключу** через `apim.moex.com/iss/datashop/algopack/...`
(или MOEX Passport через `iss.moex.com/iss/datashop/algopack/...`).
**🔑 Ключ живёт ТОЛЬКО на сервере** (прокси в api.php, как fn=iss). В браузер не отдаём.
Лицензия: перераздавать публично нельзя — фичи прячем за логином.

## 1. Наборы данных AlgoPack (что вообще есть)
| Набор | Рынок | Ключевые поля |
|---|---|---|
| **TradeStats / SuperCandles** (50+ полей) | eq/fo/fx | o/h/l/c, vwap, vol/val, **агрессор**: vol_b/vol_s, val_b/val_s, pr_vwap_b/pr_vwap_s, trades/trades_b/trades_s, disb, pr_std |
| **OrderStats** | eq/fo/fx | выставлено/снято заявок и объёмов, дисбаланс заявок (спофинг/айсберги) |
| **OBStats** | eq/fo/fx | число ценовых уровней, спред min/max/avg, ликвидность, дисбаланс бид/аск |
| **FUTOI** | fo | pos_long/pos_short, pos_long_num/pos_short_num — по физ/юр лицам |
| **Futures TradeStats** (доп.) | fo | oi_open/high/low/close (ОИ в свече!), im (гарант. обеспечение), sec_pr_* (цена БА) |
| **HI2** | — | индекс Херфиндаля-Хиршмана (концентрация потока, hhi_aggressive), формат metric/value |
| **MegaAlerts** | eq/fo | alert_type, threshold, value, **reference** = JSON статистики поведения цены после похожих алертов за 90 дней |

Опционные уровни/греки — из **опционной доски** (не AlgoPack):
`engines/futures/markets/options/securities` → SECID, ASSETCODE, UNDERLYINGASSET,
OPTIONTYPE(C/P), STRIKE, LASTDELDATE, (PREV)OPENPOSITION, THEORPRICE (+ IV/греки для GEX).

## 2. Терминал Cluster — карта модулей (6 листов)
Дропдаун слева-сверху: Cluster · F&Y · Flow (накопит. ОИ) · Si Option · Сводка · Исследование Si/CR.
Работают 3: **Cluster**, **Si Option**, **F&Y**. Не готовы: Flow, Сводка, Исследование Si/CR.

## 3. Лист «Cluster» (footprint + маркеры)
Вкладки: Кластеры · Счета · Опционы · Ф/Ю. ТФ 5M. «Загружено N баров, K уровней».

### 3.1 Счета (счета физлиц)
Кнопки: `Ф.лонг +` (открытие лонга физиками), `Ф.лонг −` (закрытие), `Ф.шорт +`, `Ф.шорт −`.
→ **Источник: FUTOI дельта** (изменение pos_long/pos_short физиков за 5 мин).

### 3.2 Опционы (наложение на график)
`Опц. уровни` (стены кол/пут по ОИ), `GEX`, выбор серии (M — месяц, W — неделя),
`Хедж +/−`, `MaxPain`, `PCR`. Слева метки: «кол 87500 V870 · 15.10», «MaxPain 86000 · PCR 0.932»,
«пут 85000/84000». → Источник: опц. доска (+ греки для GEX).

### 3.3 Ф/Ю (bid/ask по типам лиц) — «цимес»
Кружки на свече: 🟢 `Ф/Ю bid` (агрессивно покупали), 🔴 `Ф/Ю ask` (продавали);
`+` открытие, `−` закрытие; «не определено» (?) — не разложилось. Число = нетто контрактов.
→ **Источник: эвристика** = агрессор bid/ask (TradeStats vol_b/vol_s) × изменение позиций
физ/юр (FUTOI). Разрез агрессора по типу счёта в чистом TradeStats обычно НЕТ → выводим моделью.
(Проверить: не даёт ли наш тариф готовый разрез.)

### 3.4 «ОТС объём» (нижняя гистограмма ±50k) — внебиржевой/нетто объём (уточнить).
Верхние счётчики Σ/S/iS/B/iB — агрегаты по показанным маркерам (косметика).

### 3.5 Настоящий footprint (Кластеры, «739 уровней»)
Объём по каждой цене внутри свечи → **нужны тиковые данные / полный лог сделок MOEX**,
это НЕ 5-мин AlgoPack, а отдельный тяжёлый фид. У нас есть свой профиль объёма (проще).

## 4. Лист «F&Y» (SI Open Interest Analyzer) — самая сильная аналитика
Полный разбор **FUTOI**. 4 ряда снимками ~5 мин, каждый = кол-во позиций + кол-во лиц:
`Ф.Лонг · Ф.Шорт · Ю.Лонг · Ю.Шорт`. Всё остальное — арифметика дельт (Δ к прошлому снимку и к базе=вчера).

### Пары контрагентов (главное)
ΣЛонги ≡ ΣШорты (баланс ≈0, в таблице «ΣЛ−ΣШ = −3» — контроль целостности). Δ раскрывает, кто у кого перекупил:
- 🟢 **Физик Лонг / Юрик Шорт** — физики набрали лонг, юрики шорт;
- 🔴 **Физик Шорт / Юрик Лонг** — наоборот;
- 🟠 **Юрик vs Юрик** — крупный против крупного.

Маркеры: зел.▽ снизу = Ф.Лонг, красн.▽ сверху = Ф.Шорт, оранж.● = Юрик vs Юрик; число = объём перекладки.

### Сигналы (лента справа)
Крупная/дисбалансная перекладка → флаг с %. Пример 12:45 на переломе: `Физик Шорт 1171 / Юрик Лонг 8452`
(юрики агрессивно в лонг против физиков). Это «кто с кем кому торговал» + перевес/настроение.

### Вкладка «Данные» (таблица)
Колонки: Ф.Лонг / Ф.Шорт / Ю.Лонг / Ю.Шорт. Строки:
- Кол-во позиций (абс. ОИ); Оперативно к пред.закрытию (Δ vs вчера);
- **Кол-во лиц** (физики тысячи ~9864, юрики сотни ~357);
- **Средний контракт/счёт** = позиции/лица (физик ~119, юрик ~14030 → масштаб игрока, юрики=крупняк);
- Изм. средней позиции/лицо; Баланс ΣЛ−ΣШ.
- Чистый ДОИ: перераспределение Ф→Ю / чистый набор. Оперативный снимок MOEX HH:MM, база Δ = пред. закрытие.
- Правая колонка-поток: те же 4 Δ каждые 5 мин накопительно → тренд позиционирования
  (пример: 11:15→13:10 рос Ю.Шорт → слом тренда вниз).

→ **Воспроизводимо 100% из AlgoPack FUTOI.** Нюанс: снимок ~5 мин, мелкое расхождение баланса — норма MOEX.

## 5. Лист «Si Option» (V3: Sparklines) — опционный деск
Снапшоты опц. доски в архив (у серии Si-9.26 — 16 369 снапшотов; истёкшие серии тоже хранятся).

- **Таблица цепочки** по страйкам: `Call ОИ · ΔCall · спарклайн Call · Страйк · спарклайн Put · ΔPut · Put ОИ`.
  Δ — изм. ОИ страйка с прошлого снапшота; спарклайн — внутридневная история набора ОИ. ATM подсвечен.
- **Агрегаты**: PCR ОИ, PCR объём, Max Pain, ATM, ΣОИ пут/колл, до эксп. (дней).
- **Визуал**: профиль ОИ по страйкам (PUT красн / CALL зел) + вертикали Max Pain, **GEX-магнит**
  (куда гамма тянет цену), **GEX flip** (смена режима: выше — гасит, ниже — ускоряет), **Skew** (перекос IV), цена Si.
- **Визуал ист.**: ползунок по времени — реплей наполнения страйков и хода цены между ними; тултип по страйку (CALL/PUT OI).
- История серий: фильтр Все/Квартальные/Месячные/Недельные; хранят снапшоты по каждой серии.
- Ещё: ДОИ день, IV/GEX, Крупные заявки, Заявки на свече.

→ **Источник:** опц. доска по снапшотам. Нужно: (1) серверный крон, пишущий снапшот доски каждые N мин в базу;
(2) IV/греки (гамма) для GEX/Skew — из доски или расчёт по Black-76. Апгрейд нашего OptionLevels до полного деска.

## 6. Что ложится на AG-TS (сводка + сложность)
| Фича | Источник | Сложность |
|---|---|---|
| Счета физлиц (лонг/шорт откр/закр) | FUTOI дельта | низкая |
| F&Y (разбор ОИ, пары контрагентов, поток, сигналы) | FUTOI | средняя |
| Опц. стены (есть) → MaxPain/PCR | опц. доска (расчёт) | низкая |
| GEX-магнит / GEX flip / Skew / хедж | опц. доска + греки | средняя |
| Ф/Ю × bid/ask × откр/закр (маркеры) | FUTOI + TradeStats (эвристика) | средне-высокая |
| Реальная дельта агрессоров (апгрейд) | TradeStats vol_b/vol_s | низкая |
| Спред/ликвидность/дисбаланс стакана | OBStats | средняя |
| Спофинг (снятия заявок) | OrderStats | средняя |
| Концентрация потока (HI2) | HI2 | низкая |
| Алерты с историей отработки | MegaAlerts | средняя |
| Настоящий footprint (клетки объёма по цене) | тик/лог сделок (НЕ AlgoPack) | высокая (др. фид) |
| Архив снапшотов опц. доски | серверный крон + БД | инфраструктура |

## 7. Наш угол (зачем это нам, а не «ещё один Cluster»)
Позиционирование крупняка + опционные магниты **накладываем на астро/ганн-уровни**:
- «на уровне Sq9/угле Ганна юрики массово в лонг против физиков» = подтверждение уровня;
- GEX-магнит рядом с ганн-уровнем = двойной магнит;
- слом тренда позиционирования (F&Y поток) у астро-даты = сигнал.
Мы не гоняемся за ценой — показываем, кто и как позиционируется у наших уровней.

## 9. Предлагаемая очередь (когда скажем «делаем»)
1. Серверный прокси fn=algopack (ключ на сервере) + проверочный запрос (закрыть п.8).
2. F&Y на FUTOI (позиционирование физ/юр, поток, пары, сигналы) — самое ценное «наше».
3. Опционный деск: MaxPain/PCR (сразу) → снапшот-крон → GEX/Skew/Визуал-ист.
4. Реальная дельта агрессоров (TradeStats) + ОИ в свече.
5. OBStats (стакан), OrderStats (спофинг), MegaAlerts, HI2 — по вкусу.
